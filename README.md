# Intersemestral-pagila-dvd-rental-api
Proyecto intersemestral de Base de Datos Avanzadas. Desarrollo de una API REST basada en PostgreSQL (Pagila) usando SQLAlchemy y FastAPI, con enfoque en transacciones explícitas, control de concurrencia, niveles de aislamiento, triggers de auditoría y pruebas de carga con pgbench.
